# 프레시스캐너 실측 검증 설계 (Wizard of Oz)

작성: 2026-11-24 · 상태: 시작 전 · 앱 v0는 룰 4항목 중 색·결·편평비와 결함 Veto만 구현(꼭지 미구현) · 코드 0줄, 예산 약 5~8만원(추정), 소요 약 3일

## 0. 목적
"외관 룰로 같은 매대 안의 좋은 개체를 골라낼 수 있는가"를 앱 만들기 전에 사람이 룰만 적용해서 실측으로 확인한다.
통과 못 하면 AI를 붙여도 못 한다 → 과일 코어 폐기 또는 결함 탐지만 남김.

## 1. 실험 A — 과일 (메인)
**품목: 감귤** (지금 11월 제철이라 싸고, 당도계로 측정 쉽고, 외관 신호 통설이 많음). 사과는 예비.

### 1-1. 룰 사전 고정 (시작 전에 확정, 결과 보고 수정 금지)
항목별 0~2점, 합계 0~8. 이 룰은 통설 기반 가설이고 이 실험이 그 통설을 검증한다.

| 항목 | 2점 | 1점 | 0점 |
|---|---|---|---|
| 껍질 색 | 전체 균일한 진한 주황 | 일부 청색·연함 | 대부분 청색·탈색 |
| 껍질 결 | 모공 촘촘, 매끈 | 보통 | 거칠고 모공 큼, 들뜸 |
| 편평비(가로/세로) | 확실히 납작 | 보통 | 둥글거나 길쭉 |
| 꼭지 | 푸르고 작음 | 마르기 시작 | 검게 마름·떨어짐 |

- **Veto(즉시 최하위)**: 곰팡이, 무름, 눌림 자국
- 절대 크기는 제외(카메라로 못 잼). 같은 매대 안 상대 비교만.

### 1-2. 절차 (매대 1곳당)
1. 낱개로 고를 수 있는 매대에서 눈에 보이는 개체 10개를 한 장에 찍는다(실사용 조건). 매장 조명 종류, 촬영 제지 여부 기록.
2. 사진 보고 **직감 Top-3**를 먼저 적는다(룰 안 쓰고).
3. 그다음 룰로 10개 점수를 매겨 순위를 적는다.
4. 가능하면 가게 사장님에게 "이 중 어떤 걸 고르시겠어요?" 물어 **전문가 Top-3**를 기록.
5. 10개를 사서 바로 네임펜으로 번호를 쓴다(사진과 대조).
6. 집에서 개체별 측정: 알맹이 2~3개 즙의 Brix 평균(온도보정 ATC 당도계), 무게. 나머지 반쪽은 블라인드 시식 1~5점(보조).

### 1-3. 규모
- 매대 5곳 × 개체 10개 = 50개. 시장·과일가게 3곳 + 낱개 판매 마트 2곳.
- 매대별 순위상관의 표준오차가 약 0.33이라 5매대 평균 SE는 약 0.15다. **탐색용이라 방향성만 판정**한다고 명시.
- 부수 발견: **낱개로 직접 고를 수 있는 매대 비율**(마트는 박스·봉지 포장이 많음)도 기록 → 제품 가설 검증.

### 1-4. 판정 기준 (사전 확정)
| 지표 | 통과 | 탈락 |
|---|---|---|
| 룰순위 vs Brix순위 Spearman ρ, 5매대 평균 | ≥ 0.4 (그리고 5곳 중 4곳에서 ρ>0) | < 0.2 |
| 룰 Top-3 중 실제 Brix Top-3 개수 평균 | ≥ 1.8개 (무작위 기대 0.9) | < 1.2 |
| 룰 ρ − 직감 ρ | ≥ +0.1 (룰이 직감보다 낫다) | ≤ 0 |
| Veto 판정 개체 중 실제 불량(Brix 하위 30% 또는 상함) | ≥ 70% (Veto 5개 미만이면 판정 보류) | < 50% |

- 전부 통과 → 통과. ρ 0.2~0.4 회색지대 → 룰 보강 후 2차(다른 품목 1개).
- 룰이 직감보다 안 낫거나 ρ<0.2 → **과일 외관 룰 순위는 폐기**, 결함·신선도 경고만 남기고 정육 중심으로 재판단.

### 1-5. 한계(미리 인정)
- Brix는 당도일 뿐 맛(산도·향·식감)이 아님 → 시식 점수를 보조 지표로 같이 본다.
- 개체 내 편차가 커서 알맹이 여러 개 평균이 필요. 시즌·산지에 따라 결과가 달라질 수 있음(1시즌 1품목 결과).

## 2. 실험 B — 정육 팩 (병행, 규모 작게)
- 삼겹살 팩 10개(소용량 위주, 약 6만원대). 사진 → (a) 사람 눈대중 면적비, (b) 앱 알고리즘 면적비 (정육 분석은 아직 앱에 없다. 옛 구현은 태그 `legacy-expo-mock`) → 구매 후 지방·살코기 분리해 **무게비** 실측.
- 사전 정의: 지방=분리되는 흰 지방층(껍질·뼈 제외), 살코기=근육.
- 지표: 면적비 vs 무게비 오차 MAE. **통과 ≤ 5%p**, 초과면 "순수 살코기 단가" 첫 사용 이득 재설계.
- 10팩이라 오차 추정이 거칠다는 점을 보고에 명시. 구매한 고기는 먹는다.

## 3. 기록 방식
- 시트: `실측기록_시트.csv` (과일), 정육은 같은 파일 아래 블록.
- **사진 원본은 전부 보관**. 통과하면 이게 첫 라벨 데이터(룰 점수·Brix 정답 포함)가 되어 검출기 파인튜닝·평가에 쓰인다.
- 촬영 제지·조명 이슈도 로그에 남김(현장 리스크 증거).

## 4. 결과 후 분기
- 통과 → 앱의 `Scorer.kt` 임계값을 실측 값으로 보정하고(옛 `expert_scoring_engine.py`의 동적 가중치·Veto 구조는 태그 `legacy-expo-mock` 참고), 전문가 인터뷰로 룰 보강.
- 회색 → 룰 보강 후 2차 품목.
- 탈락 → 노션 검증 상태를 폐기 또는 정육 피벗 재판단으로 변경.
